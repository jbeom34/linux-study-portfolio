# Linux 기본 명령어 학습

## 1. 학습한 명령어

| 명령어 | 기능 |
|---|---|
| pwd | 현재 작업 디렉터리 확인 |
| ls | 파일 및 디렉터리 목록 확인 |
| cd | 디렉터리 이동 |
| mkdir | 디렉터리 생성 |
| touch | 파일 생성 또는 파일 시간 정보 갱신 |

## 2. 실습 명령어

```bash
pwd
ls
cd
mkdir
touch
```
