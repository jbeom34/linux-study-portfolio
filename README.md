# Linux Study Portfolio

안녕하세요! Linux와 WSL을 공부하면서 배운 내용을 정리하는 학습 포트폴리오입니다.

## 1. 프로젝트 소개

이 저장소는 Linux 기초부터 시작하여 다양한 리눅스 명령어와 시스템 관리 방법을 학습하고 기록하기 위해 만들었습니다.

학습한 내용을 직접 실습하고, 명령어의 사용법과 실행 결과를 Markdown 문서로 정리합니다.

## 2. 학습 환경

- 운영체제: Windows
- Linux 환경: WSL (Windows Subsystem for Linux)
- 배포판: Ubuntu
- 버전 관리: Git
- 자료 저장 및 공유: GitHub
- 문서 작성: Markdown

## 3. 학습 목표

- Linux 기본 명령어 이해 및 실습
- Linux 디렉터리 및 파일 관리
- 사용자와 그룹 관리
- 파일 권한 및 소유권 이해
- Shell Script 기초 학습
- Git과 GitHub를 활용한 학습 자료 관리
